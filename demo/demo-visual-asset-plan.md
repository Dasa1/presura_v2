# Demo Visual Asset Plan

This document plans the generated placeholder visual assets that will be placed under the `public/demo-assets/` directory to improve the overall presentation quality.

## Visual Direction
- **Feel:** Conservative, credible, highly professional, and service-oriented.
- **Palette:** Dark slate/navy backdrop with orange-amber highlights.
- **Image Safety Boundary:** Every image is a demo placeholder. No images should contain fake credentials, fake ratings, fictional customer names, readable text, or brand logos (e.g., Vaillant marks).
- **No Proof Representation:** Generated demo images must **never** imply that they show real Presura work, real customer work, completed projects, customer proof, case studies, or testimonials.

## Metadata & Alt Text Safety Rules
- **Alt Text Requirement:** All webp assets must have alt texts starting with `"Demo placeholder: ..."`. The alt text must **never** imply that the image represents real work, real proof, or a real Presura project.
- **Asset Registration:** All assets must be classified as a `DEMO_PLACEHOLDER_ASSET` in lists.
- **LAUNCH BLOCKER:** Owner must approve, replace, or authorize retention of these placeholders before public launch.
