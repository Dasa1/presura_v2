# 04 UX Spec

## UX principle

Urgency and trust determine conversion. Emergency users get a frictionless call path; research users get proof, pricing and a qualified inquiry path.

## Core flows

### Emergency call flow
Entry: mobile search -> service/problem page.
Required: answer what problem is solved, service area, availability and click-to-call within first viewport.

### Qualified inquiry flow
Entry: service/pricing/case page.
Required: problem education, proof, pricing anchor, short secure form and expectation-setting microcopy.

### CMS editing flow
Editor updates structured content without breaking layout or schema.

## Acceptance criteria

- Primary flow can be completed without training.
- Mobile path is first-class.
- Empty/loading/error/success states are designed.
- Accessibility is designed before implementation.

NOT SPECIFIED: exact brand assets, final copy, final legal/privacy text, and production contact details require human approval.
