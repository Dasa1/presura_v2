# 05 UI System

## Direction

Professional, technical, trustworthy and local. Avoid generic stock-heavy tradesman visuals. Use real work photos, clean grids, high contrast and restrained motion.

## Tokens

- Typography: neutral sans-serif; readable body text; strong numeric/date clarity.
- Spacing: 4/8px rhythm.
- Radius/shadow: restrained; components should feel stable, not decorative.
- Motion: respects prefers-reduced-motion.

## Components

- Header/navigation
- Sticky mobile call CTA
- Hero sections
- Trust bar
- Service/problem/location cards
- Pricing anchors
- FAQ accordion
- Before/after proof blocks
- Accessible contact form
- Cookie consent banner

## Accessibility UI requirements

- Focus-visible state is obvious and not obscured.
- Touch targets minimum 44x44 CSS px.
- Semantic labels for forms and interactive grid controls.
- Color is never the only signal.
