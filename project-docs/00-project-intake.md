# 00 Project Intake

## Project identity

Project name: Presura technical service lead-generation website

One-sentence idea: Astro + Sanity lead-generation website for a local technical service business, optimized for emergency mobile calls, service/problem/local SEO pages, performance, accessibility, GDPR-aware analytics and trust-building content.

Project type: Public website / Content SEO site

## Problem

Local technical service buyers need a fast, trustworthy way to find the right service, call in emergencies and request qualified offers for complex heating/water projects.

## Target users

Primary users: homeowners/property owners in Osijek/Bilje region; service business owner/editor

Secondary users: SEO/content editor, technical implementer, future template clients

User skill level: mixed; product must hide technical complexity.

## Desired outcome

MVP promise: a fast, credible, SEO-ready website that converts urgent mobile visits and qualified complex-service leads.

## MVP scope

MVP must include:
- Homepage with trust bar, service navigation and sticky mobile call CTA
- Up to 6 service landing pages
- Pricing/inquiry page with transparent ranges and contact form
- 2-3 problem pages
- 2-3 local landing pages with unique local proof content
- FAQ/schema, core LocalBusiness/HVACBusiness structured data
- Minimal Sanity CMS schemas for services, problems, locations, works, prices, FAQs and media
- Basic security, anti-spam, privacy analytics, accessibility and performance baseline

Explicitly out of scope for MVP:
- CRM integration
- mass programmatic local page generation
- A/B testing platform
- advanced configurators
- multi-client template SaaS packaging
- large blog program before real expert review

## Risk intake

Auth/login: Yes for CMS admin only. Personal data: Yes, inquiry form data and possible contact details. Payments: No. Uploads: Yes, CMS media only. Admin: Yes, Sanity Studio. AI/LLM features: No.

APPROVED: The technical-service-website and croatian-scheduling-saas packs remain separate. This workflow proceeds only with technical-service-website. SaaS requirements, architecture, risks, roadmap items and tasks are excluded from this project.
