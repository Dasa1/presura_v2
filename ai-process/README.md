# AI Process Pack v1.4 Context

Status: INCLUDED  
Project: technical-service-website / Presura

This package includes v1.4 build and handover documentation expectations adapted to the approved Presura technical-service website workflow.

Source hierarchy:

```text
/project-docs = what should be built and why
/tasks = execution boundaries
/build-notes = what happened during each build phase
/verification = evidence and proof
/docs = how to run, maintain, operate and transfer the project
```

Core v1.4 rules applied:

- Every implementation phase should create or update `/build-notes/phase-XX-[name].md`.
- No professional handover without owner-facing documentation.
- No CMS launch without CMS editor guide.
- No transfer-ready delivery without account-access handover checklist.
- No PASS without evidence.
- Never document passwords, API keys, tokens or secret values.
