## Root Cause
Vercel's build environment uses pnpm v9 by default. The project's `pnpm-lock.yaml` was generated by pnpm v11.5.2, which produces a **multi-document YAML** lockfile (two documents separated by `---`). Vercel's pnpm v9 parser rejects this format with:
```
The lockfile is broken: expected a single document in the stream, but found more
```

Subsequent fallback attempts (ignoring lockfile, forcing different Node/pnpm versions) all failed due to secondary incompatibilities.

## Fix Applied
1. `package.json`: Changed `packageManager` from `pnpm@11.5.2` to `pnpm@9.15.9`
2. `pnpm-workspace.yaml`: Changed from `allowBuilds` (pnpm v10+ feature) to `packages: []` (pnpm v9 compatible)
3. `pnpm-lock.yaml`: Regenerated with pnpm v9.15.9 (single-document format)
